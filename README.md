QMD Project - Starter Bundle
============================

This repository is a starter bundle for the Quantum Motor Driver (QMD) project. It contains:
  - docs/: Deliverables, memos and summaries (plain text)
  - src/: Runnable demo scripts (synthetic data, replace with real DE4 code)
  - utils/: small helper modules
  - results/: expected output folders
  - requirements.txt, LICENSE (MIT), manifest.json

Quick start:
  1. Unzip QMD_Project.zip (or use the QMD_Project folder directly).
  2. Create and activate a venv, then: pip install -r requirements.txt
  3. Run example: python src/deliverable_B1_base_surrogate.py
  4. Inspect CSVs in results/.

Notes:
  - Scripts are intentionally small synthetic demos so users can run without external data.
  - Replace placeholder DE4 surrogate implementations with production code where marked.
