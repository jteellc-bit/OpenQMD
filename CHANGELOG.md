# OpenQMD CHANGELOG

## [v1.0.0] - 2025-10-20
### Added
- Initial release of OpenQMD framework.
- Includes: README.md, LICENSE, CONTRIBUTING.md, ROADMAP.md, GOVERNANCE.md, and COMMUNITY folder.
- DE5 Context Initialization Package integrated with OpenQMD-DE5 module base.
- Manifesto paragraph finalized as end statement of Paper 4.

### Notes
This version marks the public open-source release of OpenQMD under the Open Energy Collaboration License (OECL).

Future versions will incorporate DE5 recursive coherence engine, multi-layer QMD simulation modules, and cross-sensor calibration libraries.
